# Vibe Monitor

**Architecture decision intelligence for AI-assisted software development.**

Vibe Monitor helps developers understand whether a software project is staying healthy as AI adds features, what deserves attention next, and how architecture evolves over time.

## Open-source release: in preparation

This is the new **public Vibe Monitor repository**, initialized with a clean Git history. The source-code audit, license review, Cloud/private policy separation, and Linux/Windows/macOS CI are still underway. **No Community client source or open-source license has been published here yet.**

The Community, Pro and Team plans will use **one Vibe Monitor client**. Community will offer an honest local architecture-analysis baseline; optional official Cloud services will supply policy profiles and additional paid intelligence. Server-side proprietary models, customer data, admin tooling and the previous private repository's Git history will not be published.

## Existing private-beta users

The existing published `@vibe-monitor/setup@beta` npm channel is a **private beta**, not the future open-source Community release. Existing activation and telemetry terms remain in effect during the transition. Do not interpret this public repository as a change to an installed beta's license or permissions.

Read the current [Telemetry & Privacy Contract v4](docs/governance/TELEMETRY_PRIVACY_V1.md). The private beta's user-facing CLI references this path.

A verified installation command, public license, source tree and contribution guidance will be added only after the Community release gates pass.
