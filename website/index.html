07 / FAQ

A few useful answers.

Is Vibe Monitor already open source?

The public repository is live, but the client source and open-source license have not been released yet. The current npm beta is privately licensed.

Does it upload my source code?

Default beta telemetry excludes source, diffs, prompts, project paths and secrets. It does send bounded architecture and usage signals under the disclosed private-beta agreement.

Does it consume AI tokens?

Local structural analysis does not require an LLM call. Optional semantic review through your coding agent can use model tokens; this is not included in the low-overhead local scan claim.

Will Community, Pro and Team need separate installs?

No. The plan is one shared client with service-level features managed by the optional official Cloud. Those plans are not yet available for purchase.
